# SC by chandraoktya

Add-in Microsoft Word untuk merapikan format skripsi secara otomatis.

## Fitur
- Setup dokumen dan template skripsi UPN
- Heading & BAB dengan shortcut (Ctrl+Alt+1 sampai 5)
- Caption gambar, tabel, dan lampiran otomatis
- Rumus dengan penomoran otomatis
- Daftar isi, daftar gambar, dan daftar tabel sekali klik
- Page numbering, section break, format painter, ekspor ke PDF

## Shortcut
| Shortcut | Fungsi |
|---|---|
| Ctrl+Alt+1 | BAB |
| Ctrl+Alt+2 / 3 / 4 | Heading 2 / 3 / 4 |
| Ctrl+Alt+5 | Heading 1 non-BAB |
| Ctrl+Alt+R | Rumus |
| Ctrl+Alt+G | Caption Gambar |
| Ctrl+Alt+T | Caption Tabel |
| Ctrl+Alt+L | Caption Lampiran |
| Ctrl+Alt+U | Update daftar |
| Ctrl+Alt+B | Section Break |
| Ctrl+Alt+P | Page Numbering |
